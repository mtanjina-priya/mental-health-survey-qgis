# Mental Health GIS Map

## Overview
This project presents a QGIS map showing the locations of universities that participated in a mental health survey conducted in Bangladesh.

## Software
- QGIS

## Data
- Survey data collected by the author.
- Administrative boundary data: DIVA-GIS.

## Note
This map was created as a GIS visualization and portfolio project. It was not included in the final research paper.
